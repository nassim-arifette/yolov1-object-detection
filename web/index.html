One object per cell

YOLOv1 cuts an image into a 7×7 grid and asks each cell to describe at most one object. When two objects share a cell, one of them is never taught to the network.

7.1 % of the objects in Pascal VOC 2007 fall in a cell that is already taken.

In short

This is a from-scratch reimplementation of YOLOv1 on Pascal VOC 2007, rebuilt so that every number it produces can be trusted: the loss follows the paper, evaluation reads every annotation, and train, validation and test are kept apart.

It asks two questions. How much does the one-object-per-cell grid cost? On VOC 2007, 1,745 of 24,640 objects cannot become a training target, up to 15.8 % for bottles. And does it matter what the confidence score learns, the box’s IoU as in the paper or a constant one? That experiment is running; no new mAP is reported on this page yet.

What a cell has to say

YOLOv1 reads a 448×448 image once and outputs a 7×7×30 tensor. Each of the 49 cells gives 20 class probabilities and two candidate boxes, each box a centre (relative to the cell), a width and height (relative to the image) and a confidence [1].

During training, an object is assigned to the one cell that contains its centre. That cell alone learns to find it. Hover a cell to see the target it receives.

The grid’s blind spot, measured

The paper names this limitation itself: the model struggles with small objects that appear in groups. The encoder makes it countable. Over the official train, validation and test lists, 1,141 of 9,963 images contain at least one object that loses its cell.

The cost is not shared evenly. Objects that come in clusters, like bottles, people and chairs, lose far more often than trains or cats, which tend to be alone and large.

What should confidence learn?

Each box also predicts a confidence. The paper defines its target as the IoU between the predicted box and the object it is responsible for, so a sloppy box should learn to be unsure. A simpler alternative trains it towards 1 wherever there is an object; the experiment keeps it as a control.

The difference matters at test time. A detection is ranked by its class probability times its confidence, and average precision rewards ranking good boxes above bad ones. Drag the box and compare the two targets.

Cleaning up: non-maximum suppression

With two boxes in each of 49 cells, several cells often fire on the same object. Non-maximum suppression keeps the highest-scoring box and removes the others that overlap it by more than a threshold. It runs per class, so a rider never suppresses her horse.

The experiment

The protocol was frozen before training. Four conditions share everything, architecture, optimiser, schedule, image order, except the confidence target and the augmentation. Each runs with three seeds.

The effects of interest are B − A and D − C for the confidence target, C − A and D − B for augmentation, each reported with its seeds, zero or negative included. Checkpoints are chosen on validation mAP; the test set is evaluated once, with VOC 2007’s 11-point interpolated AP at IoU 0.5 [2].

What this does not claim

  • It is not an exact reproduction of the paper. The network trains from scratch with BatchNorm and a 496-unit head instead of ImageNet pretraining and a 4,096-unit head. The published 63.4 mAP is not the target.
  • The “1” condition is a deliberate control, not a faithful baseline. All conditions use the corrected loss, masks and coordinate units.
  • The grid audit is not an AP loss. Measuring that requires evaluating the trained model on a defined subset.
  • No speed comparison with newer YOLO versions is made. That would need shared images, hardware and preprocessing.

The original course project

The first version of this project trained a YOLOv1 and compared it with newer YOLO releases on videos. Its curves are kept below as training diagnostics. They come from code with several bugs since fixed, measure training data, and cannot say anything about generalisation.

Run it yourself

Everything below except training runs on a CPU. The download verifies the official archives by MD5 and SHA-256 and writes the grid audit shown in Figure 2.

python -m pip install -r requirements-test.txt
python -m pytest tests -q
python download_voc.py --data-dir data
python train.py --voc-root data/VOCdevkit --out outputs/iou_aug_seed123
python evaluate.py --checkpoint outputs/iou_aug_seed123/best.pt --manifest data/manifests/test.json --voc-root data/VOCdevkit --out outputs/iou_aug_seed123_test
